# nids-setup

Instructions for setting up and running NIDS ([CAIDA NIDS project](https://www.caida.org/projects/nids/)) on the National Research Platform (NRP). Covers setting up a namespace, running a JupyterHub from that namespace, and copying data into the namespace for use by the NIDS modules.

## Guides

- [NRP & Namespace](docs/NRP_Namespace.md) — get access to NRP and request a namespace.
- [kubectl](docs/kubectl.md) — set up `kubectl` to work with your namespace.
- [JupyterHub](docs/JupyterHub.md) — deploy your own JupyterHub in your namespace.
